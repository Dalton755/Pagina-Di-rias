# Seletor Inteligente de Rotas — prévia

Prévia isolada do aplicativo, sem backend. Importa capturas de tabelas do WhatsApp, extrai rotas via OCR local e permite selecionar clusters favoritos.

O envio automático de Google Forms **não está habilitado**. O usuário revisa e abre individualmente os links.

O OCR depende inicialmente da CDN Tesseract.js e das permissões de rede. Dados pessoais inseridos no formulário do app são mantidos somente em armazenamento local do navegador.

Ramo isolado de desenvolvimento, sem alterações na branch principal.
